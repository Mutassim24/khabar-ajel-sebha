# خبر عاجل سبها — متجر إكسسوارات الهواتف

نسخة أولية واجهة متجر تفاعلية باللغة العربية RTL.

## التشغيل
افتح `index.html` في متصفح حديث. لا تحتاج هذه النسخة إلى تثبيت.

## الوظائف في النسخة الأولية
- عرض أقسام المنتجات.
- بحث وتصنيف وفرز.
- إضافة للسلة مع حفظها في `localStorage`.
- المفضلة محفوظة محلياً.
- واجهة إتمام الطلب عبر واتساب (رقم الهاتف يحتاج إعداد).
- واجهة responsive للموبايل والكمبيوتر.

## ملاحظات مهمة
- أسماء المنتجات والأسعار والكميات الحالية بيانات نموذجية للعرض، وليست مخزون المحل الفعلي.
- هذه نسخة Frontend Prototype. ليست متصلة بقاعدة بيانات ولا تحتوي على دخول إدارة آمن أو دفع إلكتروني.
- لتطويرها إلى نظام إنتاج: إعداد Backend وقاعدة PostgreSQL/Supabase، مصادقة، صلاحيات، لوحة إدارة، ربط المخزون والطلبات، وتعيين رقم WhatsApp.
- لتعيين رقم واتساب: داخل `app.js` في `whatsappCheckout()` غيّر قيمة `phone` إلى الرقم بصيغة دولية بدون + أو مسافات.
