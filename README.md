# خبر عاجل سبها — متجر إلكتروني متكامل

متجر إلكتروني عربي (RTL) لإكسسوارات الهواتف وقطع الغيار، مع لوحة تحكم إدارية، قاعدة بيانات حقيقية، أسعار جملة وقطاعي بالدينار الليبي، وطلبات عبر الموقع وواتساب.

- **التقنية:** Node.js 22 بدون أي مكتبات خارجية (لا يحتاج `npm install`) + قاعدة بيانات **SQLite** المدمجة في Node.
- **الحجم:** خادم واحد وقاعدة بيانات في ملف واحد (`data/store.db`) تشمل المنتجات والصور والطلبات والعملاء، والنسخ الاحتياطي بضغطة زر.

---

## التشغيل على جهازك

المتطلبات: Node.js 22.5 أو أحدث.

```bash
cp .env.example .env        # عدّل ADMIN_EMAIL و ADMIN_PASSWORD
# لتجربة محلية على http اجعل NODE_ENV=development داخل .env
node server.js
```

- المتجر: http://localhost:3000
- لوحة التحكم: http://localhost:3000/admin

لإضافة الـ 12 منتجاً التجريبية من النسخة القديمة: `SEED_SAMPLE_PRODUCTS=true node server.js` (تعمل فقط إذا كانت قاعدة البيانات فارغة).

نسيت كلمة المرور؟ من سطر أوامر الخادم:
```bash
node scripts/reset-admin.js admin@example.com "كلمة-مرور-جديدة-قوية"
```

## النشر على الإنترنت (Render — موصى به)

يحتاج المتجر **قرصاً دائماً** لحفظ قاعدة البيانات، لذلك تلزم خطة مدفوعة (الخطة المجانية في Render لا تدعم الأقراص، وتمحو البيانات عند كل إعادة تشغيل).
التكلفة التقريبية: خدمة Starter + قرص 1GB (‏0.25$ للجيجابايت شهرياً). راجع الأسعار الحالية في render.com/pricing قبل الاشتراك.

1. ارفع هذا المجلد إلى مستودع GitHub خاص (Private).
2. في Render: **New → Blueprint** واختر المستودع. سيقرأ الملف `render.yaml` تلقائياً.
3. أدخل `ADMIN_EMAIL` و `ADMIN_PASSWORD` (كلمة مرور قوية، 10 أحرف على الأقل) عندما يطلبها.
4. اضغط **Apply**. بعد دقيقة يصبح المتجر متاحاً على رابط مثل `https://khabar-ajel-sebha.onrender.com`.
5. ادخل إلى `/admin` ← **إعدادات المتجر** وأدخل رقم واتساب ومناطق التوصيل وطرق الدفع، ثم أضف المنتجات.

أي تعديل ترفعه إلى GitHub يُنشر تلقائياً، والبيانات تبقى محفوظة على القرص.

### على VPS خاص (Ubuntu 22.04/24.04) — بأمر واحد

من Terminal السيرفر (كـ root):
```bash
git clone https://github.com/Mutassim24/khabar-ajel-sebha.git /opt/khabar   # يطلب اسم المستخدم و Token لأن المستودع خاص
cd /opt/khabar && bash scripts/install-vps.sh khabarsebha.com you@example.com
```
السكربت يركّب Node.js 22 و Caddy (HTTPS مجاني) وخدمة دائمة، ويطبع كلمة سر لوحة التحكم في الآخر. اربط الدومين (سجل A) على IP السيرفر.

#### الطريقة اليدوية (نفس الخطوات بالتفصيل)

```bash
# 1) تثبيت Node.js 22 و git
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash - && sudo apt install -y nodejs git
# 2) تنزيل المتجر من GitHub (المستودع خاص: GitHub يطلب اسم المستخدم و Personal Access Token بدل كلمة السر)
sudo git clone https://github.com/Mutassim24/khabar-ajel-sebha.git /opt/khabar && cd /opt/khabar
sudo cp .env.example .env && sudo nano .env    # ADMIN_EMAIL, ADMIN_PASSWORD, SESSION_SECRET, DATA_DIR=/var/lib/khabar
# 3) تشغيله كخدمة دائمة
sudo tee /etc/systemd/system/khabar.service >/dev/null <<'EOF'
[Unit]
Description=Khabar Ajel Sebha store
After=network.target
[Service]
WorkingDirectory=/opt/khabar
EnvironmentFile=/opt/khabar/.env
ExecStart=/usr/bin/node server.js
Restart=always
[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now khabar
# 4) HTTPS مجاني مع الدومين (Caddy)
sudo apt install -y caddy
echo 'www.khabar-sebha.ly { reverse_proxy 127.0.0.1:3000 }' | sudo tee /etc/caddy/Caddyfile && sudo systemctl reload caddy
```
للتحديث لاحقاً: `cd /opt/khabar && git pull && systemctl restart khabar`. قاعدة البيانات في `DATA_DIR` ولا تتأثر بالتحديث؛ خذ نسخة احتياطية من لوحة التحكم دورياً.

### بدائل
- **Fly.io:** الملف `fly.toml` جاهز: `fly launch --no-deploy` ثم `fly volumes create store_data --region fra --size 1` ثم `fly deploy`.
- **Railway** أو أي خادم VPS: استخدم `Dockerfile` مع ربط مجلد `/data` بقرص دائم.
  ```bash
  docker build -t khabar-store .
  docker run -d -p 3000:3000 -v khabar_data:/data -e ADMIN_EMAIL=... -e ADMIN_PASSWORD=... -e SESSION_SECRET=... khabar-store
  ```
  وضع الخادم خلف HTTPS (مثل Caddy أو Nginx مع Let's Encrypt).

## ربط دومين خاص (مثل khabar-sebha.ly أو khabarsebha.com)

1. اشترِ الدومين من أي مسجّل (لنطاق ‎.ly‎ عبر مسجّل معتمد لدى إدارة نطاق ليبيا، أو ‎.com‎ من Namecheap/Cloudflare...).
2. في Render: افتح الخدمة ← **Settings → Custom Domains → Add** وأدخل الدومين (مثلاً `www.khabar-sebha.ly`).
3. عند مسجّل الدومين أضف سجلات DNS التي يعرضها Render:
   - للنطاق الفرعي `www`: سجل **CNAME** يشير إلى `khabar-ajel-sebha.onrender.com`.
   - للنطاق الرئيسي: سجل **A** بعنوان IP الذي يعطيه Render (أو ALIAS/ANAME إن كان المسجّل يدعمه).
4. انتظر انتشار DNS (من دقائق إلى 24 ساعة). يصدر Render شهادة HTTPS مجانية تلقائياً.
5. في لوحة التحكم ← الإعدادات ← **رابط الموقع الرسمي** اكتب `https://www.khabar-sebha.ly` لتُستخدم في خريطة الموقع وروابط المشاركة.
6. أضف الموقع إلى Google Search Console وأرسل خريطة الموقع: `https://www.khabar-sebha.ly/sitemap.xml`.

## المنتجات الحقيقية والأسعار

- عند أول تشغيل يُحمَّل كتالوج المتجر الحقيقي من `seed/catalog.json` مع صوره المعالجة في `seed/images/` (119 منتجاً حالياً)، والأقسام الرئيسية والفرعية.
- المنتج الذي سعره 0 يظهر للزبون **«السعر عند الطلب»** مع زر للسؤال عبر واتساب، ولا يمكن إضافته للسلة.
- **لإضافة الأسعار دفعة واحدة:** افتح `seed/prices-template.csv` في Excel، املأ السعر وسعر الجملة والتكلفة والكمية، احفظه CSV UTF-8، ثم من لوحة التحكم ← المنتجات ← «استيراد CSV». يتم تحديث المنتجات حسب رقم SKU فقط بدون المساس بالأسماء والصور.
- في ملف الاستيراد يُكتب القسم الفرعي هكذا: `الشواحن > وصلة (خيط شحن)`.
- البحث يفهم المسميات الليبية والفصحى والإنجليزية كمعنى واحد (كفر = جراب، خيط شحن = وصلة = كابل، ماكينة زيان = ماكينة حلاقة...). القائمة في `src/util.js` (SYNONYM_GROUPS).

## ما الذي يتضمنه المتجر

### واجهة المتجر
- تصميم Mobile-First بهوية المتجر (أزرق داكن + برتقالي + خط Cairo)، شريط تنقل سفلي للجوال وزر واتساب عائم.
- **وضع ليلي / نهاري** بزر في أعلى الصفحة (يُحفظ اختيار كل زبون على جهازه)، ولوحة التحكم فيها نفس الزر.
- **رقمين واتساب**: الزبون يختار أي رقم يراسل. الرسالة جاهزة تلقائياً فيها اسم المنتج ورقمه والكمية والرابط.
- الأقسام تظهر **بصور حقيقية** من المنتجات (أو صورة تختارها من لوحة التحكم ← الأقسام).
- بانرات إعلانية متحركة يُتحكم بها من اللوحة، أقسام، عروض وخصومات، منتجات مميزة، الأكثر مبيعاً، وصل حديثاً.
- **بحث ذكي:** يتجاهل التشكيل والهمزات (أ/إ/ا، ة/ه، ى/ي) ويفهم المرادفات (كفر=جراب، charger=شاحن، ايفون=iPhone...) مع اقتراحات فورية أثناء الكتابة.
- فلترة حسب القسم والسعر والتوفر والخصم والجملة، وترتيب حسب السعر والأحدث والأكثر مبيعاً.
- صفحة منتج بصور متعددة، سعر قطاعي وسعر جملة يُطبَّق **تلقائياً** عند الكمية المحددة، حالة التوفر، SKU، "اشترِ الآن"، والسؤال عبر واتساب.
- سلة كاملة، المفضلة، صفحة إتمام طلب (مناطق ورسوم توصيل، كوبون خصم، طرق دفع مناسبة لليبيا: الدفع عند الاستلام، تحويل مصرفي، محافظ إلكترونية سداد/موبي كاش/تداول).
- رقم طلب تلقائي (مثل `KH2611-0042`)، صفحة نجاح مع زر **إرسال الطلب عبر واتساب**، وصفحة **تتبع الطلب** برقم الطلب والهاتف.
- صفحات: من نحن، سياسة الخصوصية، الشحن والاستبدال، اتصل بنا (مع نموذج رسائل).
- SEO: عناوين ووصف لكل صفحة، روابط عربية، Open Graph، بيانات منظمة Schema.org للمنتجات، `sitemap.xml` و `robots.txt`.

### لوحة التحكم `/admin`
- لوحة رئيسية: مبيعات اليوم/الأسبوع/الشهر، الأرباح، رسم بياني، أحدث الطلبات، تنبيهات المخزون.
- **المنتجات:** إضافة/تعديل/حذف/نسخ، رفع صور متعددة (تُضغط تلقائياً في المتصفح)، ترتيب الصور، تعديل السعر والمخزون مباشرة من الجدول، إجراءات جماعية، **استيراد وتصدير CSV/Excel**.
- **المخزون:** سجل كامل لكل حركة (توريد، بيع، إلغاء، تعديل) مع منع البيع بأكثر من المتوفر.
- **الطلبات:** فلترة بالحالة والتاريخ، تغيير الحالة (جديد ← قيد التجهيز ← تم الشحن ← مكتمل / ملغي)، الإلغاء يعيد الكمية للمخزون، مراسلة العميل واتساب، طباعة فاتورة، تصدير CSV.
- **العملاء:** يُنشأ العميل تلقائياً من أول طلب، سجل طلباته وإجمالي مشترياته، تصنيفه قطاعي/تاجر جملة.
- **كوبونات الخصم:** نسبة أو مبلغ ثابت، حد أدنى، حد أقصى للخصم، عدد استخدامات، تاريخ بداية ونهاية.
- **التقارير:** المبيعات، صافي الربح، التكلفة، الأكثر مبيعاً، حسب القسم وطريقة الدفع والمنطقة، جملة مقابل قطاعي.
- البانرات، الصفحات، الرسائل، إعدادات المتجر (الشعار، واتساب، التوصيل، الدفع، SEO)، المستخدمون بصلاحيتين (مالك/موظف)، تغيير كلمة المرور، **تنزيل نسخة احتياطية**.

### الأمان
- كلمات المرور مشفرة بـ scrypt، جلسة في كوكي HttpOnly + SameSite=Strict + Secure، وتوقيع HMAC.
- حماية من CSRF (ترويسة مخصصة + فحص المصدر)، تحديد محاولات الدخول وإرسال الطلبات، Honeypot ضد الروبوتات.
- التحقق من كل المدخلات على الخادم، والأسعار تُحسب دائماً على الخادم (لا يمكن التلاعب بها من المتصفح).
- ترويسات أمان (CSP، X-Frame-Options، HSTS في الإنتاج). لا توجد أي مفاتيح أو بيانات إدارة في الواجهة الأمامية.
- رفع الصور يقبل JPG/PNG/WEBP فقط بعد فحص محتوى الملف.

```bash

src/store.js           المنتجات، البحث، التسعير، الطلبات، المخزون
src/views.js           صفحات المتجر (HTML من الخادم)
src/public-routes.js   صفحات المتجر و API العام
src/admin-routes.js    API لوحة التحكم
src/auth.js            تسجيل الدخول والجلسات
public/                CSS و JS المتجر، لوحة التحكم /admin
legacy/                ملفات النسخة الأولى كما استُلمت (للمرجع)
```
